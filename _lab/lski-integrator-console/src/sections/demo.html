One channel, four plugins

A Cartesian portal 4D (kinematics CartesianPortal3DA, axis TOs A1_CartesianPortal3DA…A4_CartesianPortal3DA) runs a pick‑and‑place. Scenario 1 places at a static position; scenario 2 places according to the current product counter, using LSKI_CmdMovePickAndPlace with a point and a variable reference.

Operate it

  1. 01Set the operation mode to Automatic.
  2. 02Select the scenario by including or excluding the corresponding jump command.
  3. 03Set the override to the desired value.
  4. 04Press and hold Initialize.
  5. 05Press Start.
  6. 06Press Stop.
  7. 07Try a Cycle stop — the product already in hand is placed before the program actually stops.

Operate it — through the OMAC page

  1. 01Enable the state manager.
  2. 02Request unit mode Production.
  3. 03Home all axes.
  4. 04Set the unit override to 100%.
  5. 05Reset — Stopped → Resetting → Idle.
  6. 06Start — Idle → Starting → Execute.

Any other OMAC stateOutside Execute — or while OMAC is enabled but not yet in one of the three mapped modes — every channel is forced to No operation.
Optional · run the GCode fileCopy SKI.nc onto the virtual memory card (LSKI_Demo → userFiles) and enable the commented-out commands in Processing's slot 1: Engrave Cover.
Optional · pallet-full messageThe Palletizing channel's slot 1: Start Palletize has a commented-out command that raises a message when the pallet is full; it must be acknowledged from that channel's status bar to continue.
Digital twin is off by defaultWith MCD disabled the PLC simulates the feedback itself. Switching the twin on from the Overview page requires restarting the MCD simulation and re‑homing all axes.
The manual disagrees with itself on the NX MCD versionThe components table (chapter 1.2) says "NX MCD 2506 or higher"; the setup instructions for the digital twin (chapter 3.1) say "2560 or higher". Treat 2560+ as the safer bar.
